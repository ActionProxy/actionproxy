# Glossary

## Agent

An AI system or application that proposes tool calls as part of completing a task.

## Tool call

A structured request to execute an action, such as sending an email, updating a CRM record, creating a ticket, or querying docs.

## Policy

Rules that decide whether a tool call is allowed, blocked, or requires approval.

## Approval

A human decision to allow or reject a pending tool call.

## Audit event

An append-only record of something important that happened in the lifecycle of a tool call.

## Mock tool

A local demo function that behaves like a real tool but does not call external services.
